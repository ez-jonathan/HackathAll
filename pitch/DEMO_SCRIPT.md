# 🎬 3-Minute Live Demo Script & Click-Through Guide
> **The Golden Rule of Live Demos**: Never type complex text live on stage. Use 1-click sample presets. Have the backup screen recording pre-loaded in VLC/QuickTime in fullscreen on an alternate desktop space.

---

## ⏱️ Timeline Breakdown (180 Seconds Total)

### Phase 1: The Hook & The Pain Point (0:00 – 0:30)
- **Speaker**: Speaker A (Pitch Lead)
- **Screen**: Landing page hero (`/`)
- **Action**:
  - Show the primary metric or pain point headline.
  - Say: *"Every day, [target user] spends [X hours / thousands of dollars] struggling with [pain point]. Existing solutions fail because [flaw]. Today, we built [Project Name]."*

### Phase 2: The Magic "Aha!" Interaction (0:30 – 1:45)
- **Speaker**: Speaker B (Tech Lead / Demo Driver)
- **Screen**: Application Demo (`/app` or `/demo`)
- **Action Sequence**:
  1. Click the **"Load Sample Demo"** button. (Never type manually).
  2. Point out how the input represents a real-world messy dataset or prompt.
  3. Click **"Execute / Generate"**.
  4. While the skeleton pulse animates for 1.5 seconds, explain: *"Under the hood, our engine decomposes this into [technique: vector search / agent graph / real-time solver]."*
  5. The output renders. Highlight the single most visually compelling result.

### Phase 3: Technical Edge & Architecture (1:45 – 2:30)
- **Speaker**: Speaker B
- **Screen**: Architecture modal or high-level visual
- **Action**:
  - Say: *"Unlike traditional wrappers, we implemented [Key Sponsor Tech / Custom Protocol / Agentic loop]. If connectivity drops, our fail-safe engine automatically keeps functioning with cached consensus."*

### Phase 4: Business Viability & Close (2:30 – 3:00)
- **Speaker**: Speaker A
- **Screen**: ROI / Summary view (`/pitch` or live app)
- **Action**:
  - State the immediate next step: *"We've open-sourced the scaffold, deployed live on Vercel, and our immediate milestone is [pilot user / beta test]. Thank you, we're ready for your questions!"*

---

## 🛡️ Emergency Contingency Plan
- **If Wi-Fi drops**: Switch immediately to `NEXT_PUBLIC_MOCK_MODE=true` on localhost.
- **If localhost crashes**: Swipe trackpad right to the fullscreen backup video (`pitch/backup-demo.mp4`) and narrate the video live without breaking cadence.
